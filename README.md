## Features

The program starts with a menu. Enter a number to select a feature:

| Option | Feature | Description |
| --- | --- | --- |
| `1` | Simple Calculator | Takes two numbers and an operator (`+`, `-`, `*`, or `/`) and displays the result. It handles invalid input and division by zero. |
| `2` | Question Answering Bot | Answers questions containing `hello`, `python`, `jetson`, `ai`, or `name`. It shows the available topics, continues after unknown questions, and counts questions before the user exits. |
| `3` | Turtle Drawing | Draws a colourful star spiral using Python's built-in `turtle` module, a `for` loop, changing colours, and increasing line lengths. Click the drawing window to close it. |
| `0` | Exit Program | Closes the program. |

## How to Run

1. Open a terminal in this repository folder.
2. Run:

   ```bash
   python3 "assignment 1_Li Minglong.py"
   ```

3. Select an option from the displayed menu.

> The Turtle Drawing option opens a separate graphics window. It requires a normal desktop Python environment with a display.
